How to participate
Four steps to get your project funded
Follow these steps to submit your team's innovation and claim AWS credits
1
Identify a qualifying project
Any new product, feature, or integration that consumes or changes how TechCo or TechCo customers use AWS services — including platform development, AWS solution integrations, or upgrades to existing AWS-based features.
2
Prepare your innovation plan
Gather a project summary, architecture diagram, milestone & deliverables timeline, and an AWS Simple Calculator estimate of your expected pre-production AWS spend during development and testing.
3
Submit at least 14 days before project start
No dollar threshold and no extra documentation required. Projects must be submitted at least 14 days before the start date, with a target GA date included — this helps TechCo internally prioritise submissions.
4
Credits applied to TechCo R&D account
Once approved, AWS credits are applied to TechCo's pre-production R&D AWS account — covering sandbox, dev, and test environments only. Production environment costs are excluded.
What qualifies?
If it consumes AWS services, it likely qualifies
Platform development
New TechCo platform capabilities built on AWS services.
AWS solution integration
Joint solutions or new AWS-native connectors embedded in TechCo.
Upgrades & improvements
Improving existing AWS-based features or testing new services pre-GA.
AWS service testing
Pre-production testing and evaluation of new AWS service capabilities.
FAQ
Frequently asked questions
From the official Sandbox Innovation Credit FAQ document
QCan the calculator include sandbox, dev, test, and prod costs?
Only pre-production costs (sandbox/dev/test). Credits apply to TechCo's R&D AWS account — production environments are excluded.
QIs there a threshold that triggers extra documentation?
No. There is no dollar threshold and no additional documentation required beyond the standard innovation plan.
QDo projects need to be on the roadmap before submitting?
No — but they must be submitted at least 14 days before the project start date and include a target GA date in the plan.
QDoes AWS expect a specific ROI or spending ratio in return?
AWS is not tracking ROI as a ratio. They invest because new AWS-powered TechCo products drive long-term AWS consumption from TechCo customers.
QWhat's the general rule for whether a project qualifies?
If the project will consume AWS services, or change how TechCo/customers consume AWS services, it should be considered for AWS Innovation Credits.
QIs there a set time horizon for when the project must reach GA?
No set horizon — but the plan should indicate the target GA date. This helps TechCo prioritise projects internally before submitting to AWS.
